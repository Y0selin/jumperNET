Las piezas del despliegue

  • Docker Compose crea la red red_jumper y cada servicio con límites de recursos (96–224 MB por pieza) para que nada se coma el servidor.
  • Caddy 2.8 terminale TLS de Let's Encrypt (dominio jumpernet.duckdns.org), sirve /bajares/* (estáticos, solo lectura montado en el contenedor) y /docs/* (WordPress), y distribuye el resto a la API.
  • GitHub Pages aloja el panel (React + Vite, build automático en Push). Las peticiones de datos van al dominio con Caddy — la web es 100 %% estática.
  • WordPress + MariaDB: contenedores nuevos en la misma red; SIN puertos públicos: viven detrás del handle_path de Caddy con la ruta /docs/.

El truco del WordPress en subruta

WordPress estresado bajo una subruta externa necesita dos cosas: WP_HOME y WP_SITEURL apuntando a https://dominio/docs (via WORDPRESS_CONFIG_EXTRA) y un handle_path /docs/* que quita el prefijo antes de llegar al Apache del contenedor. Con esas dos piezas, wp-admin, wp-content y wp-login funcionan coherentes.

Los golpes aprendidos (verídicos)

  • Escapes en el heredoc: escribir WORDPRESS_CONFIG_EXTRA con \" deja literalmente comillas escapadas y PHP muere con syntax error … eval()"d code. Solución: perl -pi -e 's/\\\\\\"/"/g' sobre el compose y recrear el contenedor.
  • bind mount "read-only" y caché de configuración: cambiar el fichero montado NO recrea el contenedor: hay que docker compose restart caddy para que recargue.
  • Nombre de red de docker: el compose usa name: red_jumper; los docker run auxiliares (wp-cli) deben usar --network red_jumper, no el prefijo por proyecto.
  • mariaDB lenta arrancar la 1.special: ajustado --innodb_buffer_pool_size=48M y max_allowed_packet para encajar en los límites de RAM del VPS.

Mantenimiento

  • Actualizar: docker compose pull && docker compose up -d (los datos viven en volùmenes, no se pierden).
  • Backup:data/wp_db y fichero SQLite de la API; los binarios de descargas viven en descargas/.
  • Verificación empapada: /docs 200, /bajares 200, /nodos 200, curl por 1080 con la IP del exit, CONNECT por 1081, encryption JENC activo en logs.
